Connection

Paste your deployed Google Apps Script web app URL and the access key you configured in Script Properties.

The URL and key are stored in this browser only. Do not publish your access key in a public repository.

Skip keywords

Transactions whose merchant or description contains one of these phrases are automatically skipped. Examples: credit card payment, transfer to savings.

Categories

Default categories are editable per transaction. Manual merchant category choices are remembered for future imports.

Privacy and limitations

Statement files are parsed locally in your browser; this project sends extracted transaction fields to Apps Script and stores them in your Sheet. Avoid using this on a shared computer. Text-based PDFs and CSVs are supported. Scanned/image-only PDFs need OCR, which is not included in this starter project. Always review imported transactions and categories against the original statement.
